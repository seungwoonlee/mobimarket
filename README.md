## 🌟 모비마켓이 뭐예요? (ELI5 - 3초 요약!)

> 모비마켓은 이 고민을 **1초 만에 척척 풀어주는 마법 계산기**예요!  
> 복잡한 암기나 계산기 두드릴 필요 없이, 컴퓨터 주식 화면처럼 멋지게 시세를 알려줘요.

## 🚀 어떻게 쓰나요? (초간단 3단계 시작법!)

별도의 설치 프로그램이 필요 없어요! 그냥 파일 하나만 다운받아서 켜면 끝나요. 🎈

<table width="100%">
  <tr>
    <td align="center" width="33%">
      <p><b>1단계 : 다운로드</b></p>
      <p>위의 <b>[다운로드]</b> 버튼을 눌러 <code>mobi_market.exe</code> 파일 하나만 컴퓨터에 받아요.</p>
    </td>
    <td align="center" width="33%">
      <p><b>2단계 : 게임에서 스위치 켜기</b></p>
      <p>마비노기 모바일 [환경설정] ➡️ [AI 제어] 탭에서 <b>[마비노기 모바일 AI 커넥터]</b>를 <b>ON(켬)</b>으로 켜요.</p>
    </td>
    <td align="center" width="33%">
      <p><b>3단계 : 모비마켓 실행!</b></p>
      <p>다운받은 <code>mobi_market.exe</code>를 더블 클릭하면 거래소 시세가 쫘르륵 나타나요! 💎</p>

### 시스템 요구 사항
- OS: Windows 10 / 11 (64-bit)
- Rust 1.75+ (직접 소스 코드를 빌드할 경우)

### 로컬 빌드 방법
```powershell
# 1. 저장소 복제
git clone https://github.com/seungwoonlee/mobimarket.git
cd mobimarket

# 2. 단위/통합 테스트
cargo test

# 3. 배포용 단일 바이너리 빌드 (target/release/mobi_market.exe)
cargo build --release
```

### 아키텍처 및 기술 스택
- **언어**: Rust 2021 Edition (Zero-Dependency 단일 실행 바이너리)
- **UI 라이브러리**: `eframe` / `egui` (하드웨어 가속 즉시 모드 GUI)
- **차트**: `egui_plot`
- **로컬 스토리지**: `rusqlite` (SQLite3 WAL 모드, 자동 멱등성 마이그레이션 탑재)
- **프로세스 통신**: Windows 로컬 파이프 인터페이스
- **금융공학 엔진**: Rust 네이티브 볼린저 밴드(20, 2σ), 24시간 일중 수급 주기, 수수료 10% 차감 순마진 산출
