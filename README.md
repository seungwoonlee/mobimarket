# MobiMarket (마비노기 모바일 마켓 시세 & 제작 계산기)

마비노기 모바일 거래소 실시간 시세 추적 및 제작 아이템 이득/손실 계산 데스크톱 HTS 애플리케이션입니다.

## 주요 기능

### 1. 주요 아이템 시세 모니터링 (HTS 스타일)
- **4열 고정 정렬 목록**: 품목명, 현재가(거래소 등록 최저가), 기간 최저가, 기간 최고가를 1픽셀 오차 없이 정렬하여 한눈에 파악.
- **카테고리별 그룹 필터링**: 전체, 고가템, 마력석, 영혼석, 상자류, 컬렉션 백, 잔영 장비, 해연 장비, 내 직업 장비.
- **유연한 조회 기간 설정**: 상단 헤더에서 1일, 3일, 7일, 14일, 30일, 전체 기간을 슬라이더 및 원클릭 프리셋으로 실시간 변경.
- **다중 라인 인터랙티브 시세 차트**:
  - 그룹별 비교 분석 시 변동폭이 큰 상위 5개 주요 품목 자동 선별 렌더링.
  - 최신 1위 변동 품목 네온 하이라이트.
  - 음수 방지 및 가격 변동 가시성을 극대화하는 반응형 Y축 자동 스케일링.
- **거래소 실시간 검색 & 커스텀 모니터링**: 게임 내 전체 아이템 실시간 검색 및 나만의 관심 품목 추가/삭제.

### 2. 제작 아이템 계산기
- **실시간 제작 손익 분석**: 완제품 거래소 최저가 vs 하위 재료비 합산 원가를 실시간 비교.
- **내 보유 재료 자동 연동**: 게임 캐릭터의 가방/창고 인벤토리를 실시간 감지하여 보유분 차감 후 **실제 추가 필요 비용** 및 **순수 제작 마진** 자동 산출.
- **직업별 추천 필터**: 내 직업(힐러/딜러/탱커 등)에 최적화된 장비 세트 원클릭 조회.

### 3. 마비노기 모바일 AI 커넥터 연동
- 게임 내 [환경설정] -> [AI 제어] / [마비노기 모바일 AI 커넥터]와 연동하여 실시간 시세 및 인벤토리 자동 동기화.
- 미연동 시 원클릭 가이드 팝업 및 안전한 Fallback 동작 지원.
- 1분 ~ 60분 자동 주기 조절 백그라운드 수집기 탑재.

## 스크린샷 안내

- **[시세] 주요 아이템 시세 탭**: 좌측 4열 HTS 목록 + 우측 인터랙티브 시세 변동 그래프 + 하단 수집 타임라인 테이블.
- **[제작] 제작 아이템 계산기 탭**: 완제품별 제작 비용, 보유 재료 차감 순이득, 재료별 상세 가격/수량 테이블.

## 빌드 및 실행 방법

### 요구 사양
- Rust 1.75 이상 (2021 Edition)
- Windows 10/11 x64

### 로컬 빌드
```powershell
# 저장소 복제
git clone https://github.com/seungwoonlee/mobimarket.git
cd mobimarket

# 테스트 실행
cargo test

# 최적화 단일 실행 바이너리 빌드
cargo build --release
```

빌드 완료 시 `target/release/mobi_market.exe` 단일 바이너리가 생성됩니다.

## 기술 스택
- **언어**: Rust 2021 Edition
- **GUI 프레임워크**: `eframe` (0.27) / `egui` (하드웨어 가속 즉시 모드 GUI)
- **차트/플롯**: `egui_plot`
- **로컬 스토리지**: `rusqlite` (SQLite3 임베디드 시계열 스냅샷 DB)
- **비동기 / 스케줄링**: 표준 라이브러리 스레드 + 채널 (`std::sync::mpsc`)
