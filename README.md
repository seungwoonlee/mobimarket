### 시스템 요구 사항
- OS: Windows 10 / 11 (64-bit)
- Rust 1.75+ (직접 소스 코드를 빌드할 경우)

### 로컬 빌드 방법
```powershell
# 1. 저장소 복제
git clone https://github.com/seungwoonlee/mobimarket.git
cd mobimarket

# 2. 단위/통합 테스트
cargo test

# 3. 배포용 단일 바이너리 빌드 (target/release/mobi_market.exe)
cargo build --release
```

### 아키텍처 및 기술 스택
- **언어**: Rust 2021 Edition (Zero-Dependency 단일 실행 바이너리)
- **UI 라이브러리**: `eframe` / `egui` (하드웨어 가속 즉시 모드 GUI)
- **차트**: `egui_plot`
- **로컬 스토리지**: `rusqlite` (SQLite3 WAL 모드, 자동 멱등성 마이그레이션 탑재)
- **프로세스 통신**: Windows 로컬 파이프 인터페이스
- **금융공학 엔진**: Rust 네이티브 볼린저 밴드(20, 2σ), 24시간 일중 수급 주기, 수수료 10% 차감 순마진 산출
