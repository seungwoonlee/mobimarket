# MobiMarket 요구사양서 (Requirements Specification)

> **최종 갱신일시**: 2026-11-15 18:05 (UI 레이아웃 및 직업별 장착 매핑 고도화 반영판)  
> **문서 버전**: v2.1  
> **프로젝트명**: MobiMarket (마비노기 모바일 마켓 시세 추적기 & 제작비용 계산기)  
> **개발 언어**: Rust (100% 네이티브 GUI 및 단일 바이너리)

---

## 1. 프로젝트 목적 및 핵심 가치
마비노기 모바일 공식 로컬 CLI(`MabinogiMobile_CLI.exe`)와 연동하여 거래소 실시간 시세를 모니터링하고, 주요 제작 아이템(잔영/해연 시리즈)의 최적 제작 비용을 계산하여 유저가 스마트한 거래 및 제작 결정을 내릴 수 있도록 돕는 **경량 단일 실행 파일(`.exe`) 데스크톱 애플리케이션**이다.

---

## 2. 사용자 피드백 기반 10대 핵심 요구사항

### [요구사항 1] 단일 실행 파일(.exe) 및 네이티브 GUI 창 (1200x800)
- 웹 브라우저나 웹뷰 방식을 완전히 배제하고, 화면 크기가 정돈된 **Rust 네이티브 데스크톱 창 (eframe/egui 기반, 1200x800)** 형태로 실행.
- 창 크기는 기본 1200x800, 최소 1000x600을 지원하며 반응형 다크 테마 적용.
- Windows 환경에서 텍스트가 깨지지 않도록 시스템 맑은 고딕(`malgun.ttf`) 폰트 등록.

### [요구사항 2] 실행 시 CMD 콘솔 창 및 CLI 자식 프로세스 창 깜빡임 완전 방지
- 메인 앱 실행 시 콘솔 창 방지: `#![windows_subsystem = "windows"]`.
- 백그라운드 CLI 호출 시 창 팝업 방지: Windows 프로세스 생성 플래그 `CREATE_NO_WINDOW (0x08000000)`를 적용하여 백그라운드 무음 실행.

### [요구사항 3] 포터블 데이터베이스 저장 경로 (.exe와 동일 위치)
- `%APPDATA%` 등의 숨겨진 폴더가 아닌, **실행 파일(`mobi_market.exe`)과 동일한 폴더(디렉터리)**에 `market_history.db` SQLite 파일이 자동으로 생성되고 유지됨.

### [요구사항 4] 완전 분리형 탭뷰 (TabView) 구조
- 상단 탭 전환 방식으로 화면 전체를 단일 뷰로 배타적 렌더링:
  - `[📊 주요 아이템 시세]` 탭
  - `[🛠️ 제작 아이템 계산기]` 탭

### [요구사항 5] 시세 수집 주기 기본 10분 및 최대 데이터(500개 이상) 로드
- 기본 시세 조사 주기는 **10분 (600초)**으로 설정.
- 상단 슬라이더(1분 ~ 60분)를 통해 유저가 자유롭게 실시간 조절 가능.
- `다음 수집: MM:SS` 카운트다운 표시 및 `[🔄 최저가 지금 수집]` 즉시 갱신 버튼 제공.
- 시세 그래프 및 히스토리는 서브쿼리 최신순 정렬을 통해 **최대 500개 이상**의 데이터를 로드하여 장기 추세 완벽 제공.

### [요구사항 6] 기준가격의 엄격한 단일 원칙: "최저가(MinUnitPrice)"
- 거래소의 기준가격은 **오직 최저가(MinUnitPrice)**뿐이며 다른 가격은 일체 취급하지 않음.

### [요구사항 7] 고가템 그룹 분리 및 마력석 스케일 정상화
- 33만 데카 상당의 `마력 깃든 용비늘`을 100~200데카 단위인 `마력석 3종`에서 분리.
- `👑 고가템`: 용비늘, 그랜드 앙상블 패키지, 특별 무기 선택 상자, 바람개비 모자 상자 등 수만~수십만 데카 단위 품목 독립 비교.
- `🔮 마력석`: 허상, 포식, 심해 3종 간의 정밀한 미세 시세 변동 비교.

### [요구사항 8] 잔영/해연 장비 부위 3분할 ([무기] / [방어구] / [장신구])
- 계산기 탭에서 등급 필터([전체], [해연], [잔영])와 함께 **부위 필터([전체], [무기], [방어구], [장신구])**를 복합 제공하여 원하는 파츠를 즉시 탐색 가능.

### [요구사항 9] 현재 접속 캐릭터 직업에 맞춘 장비 매핑
- 현재 접속 중인 캐릭터의 직업(예: 검술사, 댄서, 석궁사수 등 20여 개 전직 클래스)을 실시간 감지하여 해당 직업이 장착 가능한 무기 + 방어구(중갑/가죽/천옷) + 장신구를 선별 매핑.
  - 시세 탭: `[⚔️ 내 직업 장비]` 그룹을 통해 내 직업 장비 시세 즉시 비교.
  - 계산기 탭: `[x] 내 직업 전용 장비만 보기`를 통해 내 직업 장착 템을 기본 뷰로 제공.

### [요구사항 10] UI 뷰포트 전체 높이 확장 (3줄 짤림 버그 완전 해결)
- 좌측 아이템 목록, 계산기 레시피 리스트, 우측 필수 재료 명세 테이블의 `egui::ScrollArea`에 `auto_shrink([false, false])` 및 `max_height(ui.available_height())`를 적용하여 1200x800 화면 높이를 가득 채우는 쾌적한 뷰포트 보장.
- 보유량 계산은 **내가방 + 내창고 + 공용창고** 3곳 실시간 합산 유지.

### [요구사항 11] 제작 성공률 및 대성공률 기대 제작비 산출 모델
- **성공률/대성공률 정규화**: CLI 응답 백분율 데이터(0~100) 중복 곱셈 오류를 해결하여 정상적인 퍼센트(`(성공률: 90% / 대성공: 12%)`)로 표기.
- **성공률 감안 옵션 (기본 ON)**: 성공률이 100% 미만(예: 90%)인 경우 완성품을 제작하기 위한 기대 시도 횟수($1 / P_{success}$, 약 1.11회)를 산출하여 재료비 및 실구매액에 곱연산 반영.
- **대성공 감안 옵션 (기본 OFF)**: 대성공 발생 시 완제품 2개 산출(+1개 보너스) 기대치($E = P_{success} \times (1 + P_{crit})$)를 산출하여 소요 시도 횟수 감축 효과를 원가 및 부족 수량 계산에 정밀 반영.
- **동적 명세 연동**: B카드(재료 전량 구매 제작비), C카드(실구매액), 필수 재료 명세 테이블(필요 기대 수량, 부족 수량)에 토글 상태에 따른 계산 결과를 실시간 동기화.

### [요구사항 12] 단일 실행 바이너리 및 DB 파일명 .exe 일치화
- 타 PC 배포 시 오직 `mobi_market.exe` 단일 파일만 복사하여 즉시 실행 가능.
- 생성되는 파일은 `.exe`와 동일한 디렉터리에 `.exe`와 100% 동일한 이름의 **`mobi_market.db` (SQLite 데이터베이스) 단 1개**로 제한.
- eframe의 `persist_window: false` 설정을 통해 `%APPDATA%` 내 불필요한 창 위치/크기 캐시 파일 생성까지 원천 차단.

### [요구사항 13] 1280x720 기본 해상도 및 그래프 높이/범례 최적화
- 기본 앱 해상도를 **1280 x 720** (최소 1000 x 580)으로 설정.
- 그래프 상단의 찌그러졌던 가로 요약 카드(버튼들)를 완전히 제거하여 공간 낭비 방지.
- 그래프 높이를 **240px**로 축소하여 720p 해상도에서 상단 헤더, 그래프, 하단 수집 기록 테이블이 한 화면에 완벽하게 조화.
- 그래프 내 참조표(범례, Legend)에 품목명과 함께 **최신 최저가**(`품목명 (최저: N 데카)`)를 동시 표기.

### [요구사항 14] 아이템 전환 시 그래프 뷰 자동 최적 리셋 (Auto-fit Reset)
- 그래프를 줌/팬 조작한 상태에서 다른 아이템이나 그룹을 선택하면, egui_plot의 ID가 동적으로 변경(`market_plot_item_{item}`, `market_plot_group_{grp}`)되어 이전 조작 좌표가 리셋되고 해당 품목 데이터 범위에 맞춘 최적의 뷰로 자동 맞춤.

### [요구사항 15] 주요 시세 기본 조사 항목에 잔영 / 해연 장비 포함 및 시세 캐싱 완전화
- 기본 모니터링 목록(`DEFAULT_MONITORED_NAMES`)에 잔영/해연 주요 대표 장비(무기, 방어구, 장신구 18종)를 기본 포함하여 수집기가 시세를 자동 주기 수집.
- 시세 탭의 품목 그룹에 `[잔영 장비]`, `[해연 장비]` 탭을 신설하여 동일 등급 장비 간 시세를 손쉽게 다중 라인으로 비교 분석 가능.
- `refresh_data_sync` 시 `monitored_items`뿐만 아니라 `all_recipes`의 모든 장비 이름에 대해서도 스냅샷 히스토리를 함께 캐싱하여 잔영/해연 장비의 "시세없음" 현상 완전 해결.

### [요구사항 16] 재료 부족 수량 정수 올림(ceil) 및 비용 일관성
- 게임 내 재료 구매/소모 단위(정수)에 부합하도록 기대 필요 수량을 올림 정수(`ceil() as i64`)로 산출하여 `1.9개` 등 소수점 표기 결함 완전 해결.
- 부족 수량 = `(expected_req - total_owned).max(0)` 정수 산출 및 B/C 카드와 테이블 합산 금액 일치 보장.

### [요구사항 17] 추천 판정 문구 10% 임계값 세분화
- 완제품가 대비 성공률 감안 기대 제작비 차액 비율이 **10% 이상**일 때만 `강력 추천` 적용 (10% 미만은 일반 `추천`).
- 마켓 구매 역시 10% 이상 저렴할 때만 `마켓 완제품 구매 강력 추천`으로 엄격 분류.
- 마켓 매물 없을 시 `완제품 마켓 매물 없음 (제작만 가능)` 안전 안내.

### [요구사항 18] 좌측 모니터링 목록 행 전체 클릭 및 호버 인터랙션
- `ui.allocate_exact_size`를 통해 목록 항목의 가로 너비 전체(340px)를 클릭 감지 영역으로 확장.
- 행의 텍스트, 여백, 가격 어디를 클릭해도 100% 선택되며, 마우스 호버 및 선택 시 시각적 하이라이트 제공.

### [요구사항 19] 게임 내 '마비노기 모바일 AI 커넥터' 비활성화 감지 및 모달 팝업
- 마비노기 모바일 게임 프로세스(`MabinogiMobile.exe`) 실행 중이나 CLI 파이프가 미연동된 경우 최초 1회 화면 중앙에 안내 팝업 자동 호출.
- 상단 헤더 배지 옆 `[AI 커넥터 켜기 안내]` 버튼을 통해 상시 설정 방법 확인 가능.
- 팝업 내 3단계 활성화 가이드(환경설정 -> 기타/AI 제어 -> 스위치 ON) 및 `[ 다시 연결 시도 ]` / `[ 닫기 ]` 제공.

### [요구사항 20] 좌측 목록 1라인 가로 정렬 복구
- 목록 항목 내 품목명과 가격이 상하 2라인으로 나뉘던 문제를 해결하고, 좌측 품목명과 우측 가격을 단일 1라인(가로 한 줄)으로 완벽하게 일렬 배치.
- 행 전체 클릭 센스 및 선택/호버 배경 하이라이트는 그대로 유지.

### [요구사항 21] 그래프 변동량 상위 5개 선별 및 Y축 동적 스케일링
- 그룹 모드에서 품목이 5개를 초과할 때(예: 16개 등), 변동폭($max - min$) 내림차순 정렬 후 상위 5개 품목만 선별하여 그래프 라인 및 범례에 렌더링. 범례 오버플로우 문제 완전 해결.
- 무조건적인 0D 고정 바인딩 대신 실제 품목들의 최저가/최고가 범위를 기준으로 최적의 상·하한 여백을 산출하여 Y축을 동적 스케일링. 가격 변동 굴곡이 그래프 영역 전체에 역동적으로 잘 드러나도록 가시성 극대화.
