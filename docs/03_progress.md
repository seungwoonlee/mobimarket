# MobiMarket 개발 진행 상황 및 결과 보고서

## 1. 개요 및 현재 상태
- **프로젝트명**: MobiMarket (마비노기 모바일 마켓 최저가 시세 추적기 및 잔영/해연 제작비용 계산기)
- **개발 언어**: Rust 1.99 (단일 `.exe` 바이너리 배포)
- **현재 상태**: 구현 완료, 단위 테스트 100% 통과, 릴리스 빌드 최적화 완료, 전문 서브에이전트 코드 리뷰 **최종 승인(APPROVE)** 획득.
- **최종 바이너리**: `target/release/mobi_market.exe` (1,966,592 바이트 / 약 1.87 MB)

---

## 2. 주요 구현 기능 및 결과

### 2.1 공식 CLI 실측 연동 (`src/cli/`, `src/collector/`)
- `status`: 게임 클라이언트 실행 및 파이프 연결 상태(`pipe: connected`) 실시간 모니터링.
- `get_market_prices`: 20개 청크 분할 및 500ms 딜레이를 적용하여 IPC 파이프 부하 없이 주요 모니터링 품목 최저가 수집.
- `get_craftable_items`: 잔영/해연 최상위 장비 레시피 수집 및 하위 재료 품목 자동 동기화.
- 백그라운드 30초 주기 자동 수집 루프 및 UI 수동 즉시 갱신 API 연동.

### 2.2 SQLite 임베디드 스토리지 (`src/store/`)
- WAL 저널 모드, `busy_timeout = 5000`, `synchronous = NORMAL` 적용.
- `market_snapshots`: 시간대별 최저 매물가 스냅샷 저장 및 복합 인덱스 검색 최적화.
- `recipes`: 잔영/해연 장비 레시피 및 필요 재료 목록 보관.

### 2.3 제작비용 계산기 엔진 (`src/calculator/`, `tests/`)
- 오직 **최저가 (MinUnitPrice)** 단일 기준가 적용.
- 3단 원가 비교:
  - A. 완제품 마켓 최저가
  - B. 재료 최저가 전량 구매 시 제작비용
  - C. 내 가방/창고 인벤토리 보유분(`get_items`의 `Owned`) 차감 실구매 필요비용
- 5% 거래소 수수료 차감 실질 순이익, 절감액, ROI 및 추천 여부 산출.
- 단위 테스트(`tests/test_calculator.rs`) 통과.

### 2.4 단일 실행 파일(`.exe`) 및 2대 탭뷰 UI (`src/main.rs`, `frontend/dist/`)
- `rust-embed`를 통해 정적 HTML/CSS/JS 에셋을 바이너리 내부에 패킹.
- 포트 4829 기동 시 시스템 기본 웹 브라우저 자동 오픈 (`open::that`).
- 2대 독립 탭뷰: `주요 아이템 시세` vs `제작 아이템 계산기`.
- LTO, dead code 제거, 심볼 스트립으로 단 **1.87 MB** 초경량 단일 바이너리 완성.
